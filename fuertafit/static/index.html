Traer rutinas nuevas de FuertaFit

Se hace desde tu navegador con tu sesión de FuertaFit: no hace falta contraseña ni se descarga ningún vídeo, solo los datos de las rutinas nuevas.

  1. Una sola vez: arrastra este botón a la barra de marcadores (si no la ves: Ctrl+Mayús+B).
    ⟳ Actualizar Fuerta
    Cada ordenador o navegador necesita su propio marcador (apunta a ).
  2. Abre webapp.fuertafit.com e inicia sesión si te lo pide.
  3. Estando en FuertaFit, pulsa el marcador ⟳ Actualizar Fuerta. Se abrirá una ventanita con el progreso; si el navegador bloquea la ventana emergente, permítela y vuelve a pulsarlo.
  4. Cuando diga «¡Listo!», recarga esta página.

Las rutinas nuevas suelen ser pocas, así que tarda segundos. También puedes pedírmelo en Claude Code como la primera vez.
